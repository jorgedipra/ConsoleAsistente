## Descripción

ConsoleAsistente es un asistente conversacional que combina:
- Chat en tiempo real con Vue.js
- Procesamiento de lenguaje natural
- Integración con LLMs (Ollama, Claude, OpenAI)
- Comandos de voz con Web Speech API
- Base de datos para respuestas predefinidas

## Tecnologías

- **Backend**: PHP 7.4+ / MySQL
- **Frontend**: Vue.js 2.x, JavaScript vanilla
- **APIs**: Ollama (local), OpenAI, Anthropic Claude
- **Voz**: Web Speech API, Annyang
